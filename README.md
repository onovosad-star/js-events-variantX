# js-events-variantX
# Практична робота №6: Події та DOM маніпуляції

## Варіант 1: Форма з live-валідацією та real-time пошуком

Цей проект демонструє роботу з подіями JavaScript, маніпуляції з DOM деревом та реалізацію інтерактивних користувацьких інтерфейсів без використання сторонніх бібліотек.

### Функціонал

#### 1. Контактна форма з інтелектуальною валідацією:
* **Live-валідація:** Перевірка полів (Ім'я, Email, Телефон, Повідомлення) безпосередньо під час введення тексту.
* **Debounce техніка:** Оптимізація продуктивності — валідація запускається лише через 300 мс після того, як користувач припинив друкувати.
* **Візуальний фідбек:** Динамічна зміна кольорів рамок (зелена/червона) та виведення текстових підказок про помилки.
* **Progress Bar:** Графічне відображення ступеня заповнення форми (від 0% до 100%).
* **Smart Submit:** Кнопка відправки автоматично розблоковується лише після успішної валідації всіх полів.

#### 2. Компонент пошуку студентів:
* **Миттєва фільтрація:** Пошук по списку з 32 студентів у реальному часі.
* **Text Highlighting:** Підсвічування знайдених частин імені за допомогою тегу `<mark>`.
* **Empty State:** Коректна обробка ситуації, коли за запитом нічого не знайдено.

### Технічні особливості
* **Event Delegation:** Обробка подій форми реалізована через один слухач на батьківському елементі `<form>`, що покращує продуктивність.
* **Vanilla JS:** Весь функціонал написаний на чистій мові JavaScript (ES6+).
* **Accessibility:** Використано семантичні теги та базові атрибути для покращення доступності.
* **CSS Animations:** Плавні переходи для прогрес-бару та валідаційних станів.
